# PaperCode

<!-- impeccable:product-schema 1 -->

## Platform

Terminal application for desktop shells. The primary interface uses React and Ink, not a browser.

## Users

Developers working on a codebase in an interactive terminal.

## Product Purpose

Connect a model provider and use an agent to inspect, change and verify code. The user wants a production-quality terminal workspace with a centered launch composer and a persistent conversation/context layout.

## Capabilities and Constraints

OpenAI-compatible providers, streamed responses, tool execution, approval prompts, build and plan modes, MCP, skills, session history, branching and automatic compaction already exist. Preserve these behaviors and keyboard access. Adapt to terminal resizing and narrow windows. Context and configuration shown in the interface must come from actual application state.

## Brand Commitments

Keep the PaperCode name. The user requested a complete visual redesign, named OpenCode as a reference, and requested four selectable themes. Three use graphite/orange/ice-blue, midnight/cyan/lime, and paper/ink/rust. The fourth visual direction is delegated.
